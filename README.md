# bosque-tools

VS Code language support for Bosque source files.

## Features

- Syntax highlighting for `.bsq` files
- Bosque comment, bracket, and literal configuration

## Notes

The grammar follows the current lexer in `scratch/`, including Bosque's delimiter-based string, regex, glob, and path literals and the distinction between spaced `<` / `>` comparison operators and unspaced angle-bracket delimiters.
